# golos-brajan
# Голос + Брайан

Проект «Капитан и Кит». Голосовой ассистент с авторской гипотезой вычислительной интуиции.

## Что это

**Голос** — голосовой ассистент. Работает локально. Без облака. На Vosk + pyttsx3.

**Брайан** — мозг. Не нейросеть. Маленькая система. Учится на переходах. Предсказывает. Ошибается. Исправляется.

## Три точки

Брайан — не «да» и «нет». Не бинарно. А — **три точки**:

1. **Интуиция** — что будет. Предсказание.
2. **Наблюдение** — что есть. Реальность.
3. **Дежавю** — совпало или нет. Сравнение.

Цикл. Замкнут. Живой.

## Как устроено

- `GOLOS_CHROM_WITH_BRAIN.py` — Голос. Слушает. Понимает. Отвечает.
- `intuition_core.py` — мозг Брайана. Переходы. Предсказания.
- `golos_intuition_journal.json` — память. 342 цикла.
- `voice_blocks\` — блоки команд.
- `_brain_stats.py` — анализ. Статистика. Ошибки.
- `brain_errors.md` — дневник ошибок.
- `ИНТУИЦИЯ.txt` — теория.
- `команды_голоса.txt` — карта команд.

## Как запустить

1. Установить Python 3.
2. Установить зависимости:
pip install vosk pyaudio pyttsx3 pyautogui pygetwindow keyboard requests pyperclip

text
3. Скачать модель Vosk — `vosk-model-small-ru-0.22`.
4. Положить модель в `C:\models\vosk-model-small-ru-0.22`.
5. Запустить:
ЗАПУСК_ГОЛОСА.bat

text
6. Сказать: «внимание голос». Потом — команду.

## Что внутри Брайана

- **Память** — переходы A → B. С частотой.
- **Предвосхищение** — что будет. С уверенностью.
- **Восприятие** — что реально.
- **Сходимость** — MATCH / NO_MATCH.
- **Fallback** — если не знает. Берёт частое.
- **Decay** — старые переходы слабеют.
